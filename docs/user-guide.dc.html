01

Before you start

This plugin turns QGIS into a military mapping tool. It does five kinds of job: it reads and writes grid references, it draws military grids, it studies the ground from elevation data, it lays out printable map sheets, and it draws tactical symbology — NATO’s own, and a separate non-NATO scheme beside it.

You do not need to be a GIS expert. You do need to know three QGIS habits, because the plugin leans on them rather than replacing them.

Layers live in the Layers panel
Every tool here adds one or more layers down the left-hand side of QGIS. Tick a layer to show it, untick to hide it. Drag a layer up the list to draw it on top of the others.
You must switch editing on before you can draw
Click the layer once to select it, then click the yellow pencil on the QGIS toolbar. Now the drawing tools wake up. Click the pencil again when you have finished, and say Save when asked.
A symbol is just a row of attributes
You never pick a picture from a palette. You place a point, a line or an area, and then fill in a short form — side, type, status, name. The plugin draws the correct symbol from what you typed, and redraws it the moment you change your mind.
Nothing leaves your machine. There are no web services, no downloads and no telemetry anywhere in this plugin. It works on an air-gapped machine, which is the point.
02

Installing the plugin

You need QGIS 3.44 or later. There are two ways in.

From inside QGIS (easiest)

  1. Open Plugins → Manage and Install Plugins.
  2. Search for Military Cartography Tools.
  3. Click Install Plugin.

By hand, from a folder

  1. In QGIS, go to Settings → User Profiles → Open Active Profile Folder.
  2. Open python/plugins inside it, and copy the whole MilitaryCartographyTools folder in there.
  3. Restart QGIS, then open Plugins → Manage and Install Plugins → Installed and tick Military Cartography Tools.

A new toolbar appears. If you cannot see it, right-click any empty part of the QGIS toolbar area and tick Military Cartography Tools. Every tool is also listed under Plugins → Military Cartography Tools.

To open this guide again, click User Guide on the toolbar — the blue book with a question mark. It is also under Help → Plugins. The guide is a file inside the plugin and opens in your web browser, so it works with no network.

04

Military grids

These four entries draw the grids a military map is read against. They work on whatever the map window is showing right now, so pan and zoom to your area of interest first, then switch a grid on.

UTM Grid
The Grid Zone Designator boxes, such as 37M. Normally 6° wide by 8° tall. The two exceptions the standard itself makes are drawn correctly: over south-west Norway 31V is narrow and 32V is wide; over Svalbard three zones do not exist at all and their neighbours are widened to cover the gap.
MGRS 100 km Grid
The lettered 100 km squares inside each zone. Switching this on brings the UTM grid up too, because the 100 km squares are built from it.
Sub Grid → 10 km / 5 km / 1 km
The working grid lines, with tick numbers drawn on the map. Pick the spacing that suits your scale. This also brings the UTM grid up, because sub-grid lines are generated one zone at a time.
Clear Grid
Removes every grid layer at once and resets all the tick marks. Use it before you build grids for a new area.
Moved to a new area and the grid looks wrong? Each grid is built once for the area you were looking at, then simply shown or hidden. Pan to the new area, run Clear Grid, and switch the grids back on to rebuild them there.
05

Position and bearing

Coordinate Probe

Reads off the grid reference of any point you click.

  1. Click the crosshair in the Navigation menu. The tool now stays switched on, like QGIS’s own Identify tool.
  2. Click anywhere on the map. A window opens listing that click: latitude and longitude, and the MGRS reference to the nearest metre.
  3. The MGRS reference is copied to your clipboard automatically, ready to paste into a signal or a message.

Keep clicking and the list keeps growing, newest at the top. Double-click any row to copy that row’s reference again. Closing the window only hides it — your next click brings it back with the whole list intact. Choose a different tool when you want the probe to stop.

Bearing / Range

Gives you the distance and all three azimuths between two points.

  1. Click the tool, then click your from point. A blue cross marks it.
  2. Click your to point. A red X marks it, an arrow is drawn between the two, and the reading is logged.
  3. Click again anywhere to start a fresh pair. The old pair is cleared, not added to.
From / To
Latitude, longitude and full MGRS for each point.
True Az
Azimuth to true (geographic) north.
Grid Az
Azimuth to UTM grid north.
Mag Az
Azimuth to magnetic north, using the World Magnetic Model for today’s date.
Distance
Distance across the curved earth, in metres.

Both grid and magnetic azimuth are worked out at the from point — the same convention as the grid-magnetic-angle diagram on a paper map. All four figures are true earth-surface values, not flat-map approximations. The window keeps every reading until you press Clear.

06

Terrain analysis

Every tool in this section needs a DEM. A DEM is an elevation raster — a picture of the ground where each pixel holds a height. Load one into your project first. The plugin will not fetch one for you, because it never touches the network. See Getting a DEM below.

Tanaka Contours

Contour lines that get thicker where the slope faces straight into the light or straight away from it, and thinner where it runs side-on. The result reads as relief without needing any shading underneath.

DEM layer
Any elevation raster in your project.
Contour interval
Height between one contour and the next, in metres.
Segment length
How finely each line is chopped up so the thickness can change smoothly along it. Smaller is smoother but slower.
Light azimuth
Where the light comes from, in degrees. 315° (north-west) by default, the usual cartographic convention.
Min / Max width
Line thickness in millimetres at the thinnest and thickest case.
Style
Elevation colour (default) — blue below sea level, then green, yellow, brown, red, white going up. Monochrome — the classic grey Tanaka look. Illuminated overlay — black and white lines that blend with whatever is beneath, so use it over a Hypsometric Tint or the lines will be nearly invisible.
Add as new layer
Off by default, so running the tool again corrects the layer you already have. Tick it to keep the old one and compare.
This one can take a long time. A big DEM with a fine interval is a lot of work, and QGIS will just look busy rather than showing progress. The two costly settings are contour interval and segment length. Start coarse, check it looks right, then refine — or crop the DEM to your area first.

Hypsometric Tint

The filled version of the same idea — solid colour bands by height, so the space between contours is no longer blank. Made to sit underneath Tanaka Contours; generate both over the same ground and they complete each other. New layers always go to the bottom of the Layers panel, so they never bury your grids.

Opacity
0–100%. Lower it to let a base map show through.
Stepped colour ramp
Off gives a smooth blend. Tick it for hard-edged bands, the published atlas look.

Hillshade Combinations

QGIS’s own hillshade lights the ground from one direction, which hides any ridge running the same way as the light. This tool runs the calculation from two directions (north-west and north-east) or three (adding south) and averages them, so nothing is lost in the shadow of the light itself.

It arrives in grey with an Overlay blend already set. If a Hypsometric Tint is already in your project, the new layer is placed directly above it and the two combine into coloured, textured relief with no further work.

Line of Sight

Can this observer see that target?

  1. Click the tool, then click the observer (blue cross).
  2. Click the target (red X). The check runs straight away.
  3. The answer is drawn as a line: green where the target is visible, red where it is blocked. The window gives the distance and, if blocked, roughly how far along the first obstruction sits.
Observer height
Height above the ground at the observer, in metres. 1.7 by default — eye height for a standing person.
Target height
Height above the ground at the target. 0 by default — ground level.

Change a height and press Generate to run it again without re-clicking. The check allows for the curve of the earth and for the way light bends in the atmosphere, so a low target far enough away is correctly reported as hidden even over flat open ground. Water is treated as its surface, not its bed. You can pan and zoom freely between the two clicks.

Viewshed

Where Line of Sight checks one target, Viewshed sweeps every direction and shades the ground that is actually visible. Ground out of range, or hidden behind a hill, is left blank rather than filled — that blank ground is your dead ground.

Click the tool, then click the observer. That is all — each click is a complete analysis on its own.

Max distance
How far out to sweep, in metres. 5,000 by default; up to 500,000.
Opacity
How solid the shading is. 65% by default so the terrain still reads through it.
Colour
Green by default. Change it to tell several observers apart.
Outline only
Draws just the edge of the visible area. Honest but scattered — a real viewshed breaks into many small pieces that a solid fill visually glues together.

Getting a DEM

If you have no elevation data yet, the usual routes are QGIS’s own Data Source Manager (a WCS connection), or a downloader plugin such as SRTM Downloader from Plugins → Manage and Install Plugins. Both need internet access, so do this before you go off the network.

For depth below sea level, SRTM will not help — it holds land only and leaves water flat. The common free source is GMRT. There is no dedicated QGIS plugin for it, so use the GMRT MapTool website to draw an area and download a GeoTIFF, then add that as a raster layer.

Two things to know once you have depth data. Depths arrive as negative heights, and both Line of Sight and Viewshed deliberately lift anything below zero up to sea level — an observer on water sits on the surface, not the seabed. And the Hypsometric Tint already has a below-sea-level band, so it colours correctly with no extra setup.

07

Sensor coverage

Viewshed answers “what can this one observer see”. Sensor Coverage answers “what does this whole laydown cover” — several sensors plotted together, with their coverage merged into one picture.

Setting it up

Open Sensor Coverage, pick your DEM, and tick which of the three levels you need. The plugin makes a Sensor Points layer for each. That is the whole dialogue — everything else happens on the layers themselves.

Low Level
Detects up to 3,300 m (10,000 ft) above itself.
Medium Level
3,300 m to 7,000 m (10,000–25,000 ft) above itself.
High Level
Above 7,000 m (25,000 ft).
These bands are measured from the aerial, not from sea level. A radar on a 5 m mast at sea level reaches 3,305 m, so an aircraft at 3,500 m is above it and out of reach. Put the same radar on a 2,000 m plateau and it reaches 5,305 m, and that same aircraft is comfortably inside its picture. Siting a sensor higher lifts its whole band with it.

Plotting sensors

  1. Select the Sensor Points layer for the level you want.
  2. Switch editing on, then place each sensor with QGIS’s ordinary Add Point Feature tool.
  3. Fill in the form for each one.
  4. Save the layer. Coverage is drawn only when you save.
Affiliation
Friend, Hostile, Neutral or Unknown. Sets the colour, and decides which other sensors this one will merge with.
Sensor height
Height of the aerial above the ground it stands on, in metres. The DEM supplies the ground height under it.
Max detection height
How far above itself it can detect. Capped to its own band, so you cannot accidentally give a low-level point a high-level reach.
Maximum range
That sensor’s own range in metres, 30,000 by default. Deliberately not tied to the level — a man-portable set and a long-range ground-based one can both be low level.
Unique designation
Optional name. Leave it blank and the sensor is simply not labelled.
Lat / Lon / MGRS
Filled in for you and kept up to date as the sensor moves. Read-only — move the point to change them.
No coverage showing? You have almost certainly not saved. Placing or moving a sensor does nothing visible until you save the layer (Layer → Save Layer Edits, or switch the pencil off). Saving is the trigger because each sensor is a full viewshed calculation, and redoing that while you drag a point would make dragging unusable. To redraw without editing anything — after reopening a project, say — use Regenerate Sensor Coverage.

Reading the result

Coverage is drawn as an outline, not a filled shape. A laydown is several big overlapping areas stacked over the very terrain you are judging them against, and a fill washes all of that out even when see-through. The perimeter is the information.

Colour follows MIL‑STD‑2525 side — friend blue, hostile red, neutral green, unknown yellow — and the three levels are told apart by the line instead: low is a thin short dash, medium a heavier long dash, high a solid 0.6 mm line.

Coverage merges only between sensors on the same side. Two friendly radars fuse into one perimeter; a friendly and a hostile one covering the same ground stay two separate overlapping shapes. Each sensor labels its own stretch of the outline, so two merged radars give you one perimeter with a name on each half. A sensor swallowed entirely inside a larger friendly one contributes no perimeter, so it gets no label.

A suspiciously straight or rectangular edge means you ran out of terrain. Analysis stops at the edge of your DEM, corners included. Check the sensor’s range against your DEM’s extent before reading anything into that shape.
Sensor points are temporary until you make them permanent. Saving the project keeps the layer, its fields and its styling — but not the sensors you placed. To keep a laydown, right-click each Sensor Points layer → Make Permanent, save it to a GeoPackage, then save the project. Do not rename the layer afterwards; coverage is matched by name. The coverage layers themselves need nothing — they are rebuilt from the points.

Two notes on what this tool claims. Radar refraction uses the 4/3-earth model, which pushes the horizon about 15% further out than an optical sightline. And the target is modelled as flying level at a fixed altitude, so a mountain taller than that altitude genuinely hides what is behind it. Aerial tilt, beam width and radio path loss are deliberately not modelled — they need figures nobody has to hand, and guessing them produces a confident-looking contour built on invented numbers. This tool models geometry only.

Maps for printing

New Military Layout

QGIS’s own “New Layout” asks for a name and gives you a blank page. This one asks a few questions and gives you a finished military map sheet.

Name
Duplicates get a number added automatically.
Page size
Custom, A0, A3, A4 or Arch E.
Orientation
Landscape or portrait.
Width / Height
Editable only when page size is Custom.
Scale
Pick a common one or type your own, such as 1:50000.
Heading 1 / 2
Optional. Always printed in capitals however you type it. Leave both blank for no heading.
Classification
None, UNCLASSIFIED, RESTRICTED, CONFIDENTIAL, SECRET or TOP SECRET — printed as a bold banner top and bottom.

Every layout it builds already contains:

  • a north arrow that turns to true north by itself as the map rotates or its grid convergence changes;
  • a scale bar, sized sensibly for the scale you chose;
  • a metadata block (bottom left) with datum, projection, units, scale, project file and page size;
  • the centre-of-map grid reference (bottom right);
  • a neatline that tracks the map frame exactly;
  • a light geographic graticule, spaced automatically, kept visually distinct from the UTM/MGRS grid;
  • a small grid position diagram showing where this sheet sits in the grid hierarchy, with the sheet’s own footprint outlined on it to scale;
  • classification banners, if you chose one.

Margins are worked out from whatever combination of heading and banners you picked, so the map always fills the space that is left rather than leaving dead paper.

Changing a layout afterwards

Every layout window has a Military Layout Settings panel with the same fields as the creation dialogue. Change what you like and press Apply to update the layout in place — page size, scale, heading, classification — instead of starting a new layout for every revision. Your pan position survives a resize. If you close the panel, the toolbar button brings it back.

The layout toolbar

Add Grid Frame — puts tick marks and grid numbers around the edge of the map, spaced for the print scale, and hides the on-map tick labels for this layout only. This is the normal topographic convention: numbers on the neatline, not written over the map. Remove Grid Frame undoes it.
Insert Symbol — drops a MIL‑STD‑2525 symbol straight onto the page for a legend key or a callout. Pick Affiliation, Symbol Set and Entity, click Insert, then drag it where you want. It is a plain picture, not a map feature, so it has no echelon, status or modifier options — build the symbol on a map layer if you need those.

Map Sheet Series

Produces a whole numbered set of sheets tiling the area you are looking at, edge to edge with no gaps or overlap — for covering a large area of operations rather than making one sheet at a time. It asks the same questions as New Military Layout, and every sheet in the series shares those answers.

Each sheet is registered as its own print layout. They are not opened for you — a large series would mean dozens of windows at once — so find them under Project → Layouts Manager.

Sheets are named after real grid squares, not an invented numbering scheme: 37M EN #1 means Grid Zone Designator 37M, 100 km square EN. The number on the end separates sheets that fall in the same square, and it restarts at 1 for each new square so it never implies an order across the series.

A combination of page size and scale that would make more than 200 sheets is refused rather than quietly grinding away. Zoom in, or choose a smaller-scale map.

09

Waypoints (GPX / KML)

Two separate actions, for moving points between QGIS and a GPS set or ATAK. Both attach an MGRS grid reference, because neither file format has any idea of one.

Import Waypoints

  1. Click the tool, then Browse… and pick a .gpx or .kml file.
  2. Click Import. A new point layer arrives, named after the file, with every field the file already had plus a new mgrs field worked out from each point’s position.

Export Waypoints

  1. Click the tool, choose a point layer from your project, and choose GPX or KML.
  2. Browse… for where to save it, then click Export.
  3. Each waypoint’s name — the field a GPS set or ATAK actually shows on screen — is set to its MGRS reference. Any name the layer already had is kept alongside it as a description.

Zipped KML (.kmz) is not supported, and routes and tracks inside a GPX file are not imported — only standalone waypoints.

10

Unit symbols

The eight entries in the NATO Symbols menu — Space, Air, Land, Sea Surface, Subsurface, Activities, SIGINT, Cyberspace — each add one or more point layers. Every point you put on one of these layers draws itself as the correct military symbol, worked out from the attributes you fill in.

Placing a symbol

  1. Click the domain you want in the NATO Symbols menu. The layer or layers appear, empty and ready.
  2. Select the layer, switch editing on, and click a position with QGIS’s own Add Point Feature tool.
  3. Fill in the form that pops up. The symbol appears as soon as the attributes are saved — there is no regenerate step.

To change a symbol later, open the attribute table or the identify form and edit the fields. Snapping, undo and vertex editing all work as normal, because these are ordinary QGIS point layers.

The fields every layer has

Affiliation
Friend, Hostile, Neutral or Unknown — this is what gives you the blue, red, green or yellow frame.
Entity
What the thing actually is. Open the dropdown to see the whole vocabulary for that domain.
Status
Present, or Planned — planned symbols draw with a dashed outline.
Unique designation
Free text label, such as 1-501 IN.
Rotation
Degrees clockwise from north. Turns the whole symbol as one picture — echelon ticks and text included — not just the icon inside.
Scale
Percentage of the symbol’s normal size. 100 is normal.

Extra fields, where the standard allows them

Not every field applies to every domain — a battalion has an echelon, a single aircraft does not — so each layer only shows the fields its own part of the standard defines.

Echelon — Team/Crew up through Theatre, plus Command. Land Unit and the Boundary line measure only.
Headquarters — a tick box marking the symbol as a headquarters element. The four Land layers.
Sector 1 / Sector 2 Modifier — a second, smaller icon beside the main one: a ship’s warfare role, a submarine’s propulsion, a radar or jammer category. Each has an explicit (None) option.
Dimension — SIGINT only. Its four entities mean the same thing in every dimension, so this field says whether this one is a space, air, land, sea surface or subsurface intercept.

All of these carry the full vocabulary of their part of the standard, with one exception: Land Unit is still a curated common-vocabulary subset organised by function — manoeuvre, fires, air defence, combat support, intelligence, combat service support. Nothing is missing from the drawing engine; it is only the list that is shorter.

These layers hold your data, so the plugin will never overwrite one. Everything else in this plugin is worked out from a DEM or a grid and can safely be rebuilt. These hold hand-placed operational information, so clicking a menu entry again when the layer already exists gives you a warning instead of a fresh empty layer. Rename the existing one first if you genuinely want a second.

Symbology edition

The Symbology Edition button picks which standard newly added layers are built against: MIL‑STD‑2525D / APP‑6D, which is the default, or MIL‑STD‑2525E / APP‑6E. It is remembered between sessions.

Changing it never touches a layer already in your project. Each layer’s rendering is fixed the moment it is created, so old work keeps drawing exactly as it always did. Both editions can live side by side: add Air once under each and you get two layers, named Air (2525D/6D) and Air (2525E/6E). A symbol cannot mix editions, because the standard itself defines the vocabularies differently.

2525E’s vocabulary is noticeably larger than 2525D’s in places, Land Unit especially, and it drops a few codes 2525D retired. APP‑6E is not built as a separate vocabulary — it is close enough to 2525E that the one edition serves both.

Not built: METOC. Appendix I — meteorological and oceanographic symbols, so pressure systems, fronts, sea ice, wave heights — is not included. The underlying symbol library has no support for it, so all 400-odd symbols would have to be hand-drawn. Say the word if you need it.
11

Control measures

Unit symbols say what is where. Control measures say what the ground is for — boundaries, phase lines, objectives, minefields, obstacles, fire support areas, mission tasks. The whole of the standard’s Appendix H is built, and the Control Measures menu has one entry per logical group so the list never becomes one unmanageable pile.

Each entry adds the layers that group needs — typically a Lines layer, an Areas layer and a Points layer, though plenty of groups only need one or two. Every layer arrives empty and ready. Clicking an entry again is safe: each layer is checked on its own, so you only get back whichever ones are missing.

How a control measure gets drawn

Always the same three moves, whatever the measure: draw the geometry, pick the Entity, fill in the rest of the form. You use QGIS’s own Add Line Feature, Add Polygon Feature or Add Point Feature tool — there is no special drawing mode to learn. The Entity field is what decides which symbol your geometry becomes.

Affiliation
Friend blue, Hostile red, Neutral green, Unknown yellow, and — unique to control measures — Unspecified, which draws black and is the default. Colour only; the shape never changes.
Entity
Which measure this is. Different for every layer.
Status
Present draws solid, Planned draws dashed. A few measures are always dashed by definition — Probable Line of Deployment, Coordinated Fire Line, Decoy/Dummy, Follow and Assume, Counterattack — and those ignore this field.
Unique designation
The name. Always printed in capitals however you type it, because the standard requires it. Where it goes depends on the measure.
Echelon
Lines layers. Draws the amplifier — I, II, X, XX and so on — used by Boundary, Battle Position and Strong Point. On Battle Position and Strong Point it sits in the perimeter itself, halfway along the first segment you drew, with a real gap cut in the line around it.
Rotation, Scale
Points layers only. Lines and Areas take their angle and size from the geometry you drew, so they have neither.
Length and area fill themselves in. Lines layers have a Length (km) field; Areas layers have Area (km²) and Perimeter (km). All three are worked out the moment you finish drawing, and kept right if you reshape the feature later. Nothing to type.
Two things behave differently from the unit symbols. Obstacles draw green rather than in the affiliation colour, and have their own Colour field so you can switch any single one to black — the water crossing sites default to black, since a crossing is the opposite of an obstacle. And on the Sustainment, Supply and Mission Task point layers, friendly, neutral and unknown all draw black while hostile draws red, which is the standard’s own rule for those tables.

Labels cut real gaps in the line

Wherever a letter or a name sits on a line or a perimeter — a boundary’s echelon, the “B” on a Block, the ring numbers on a safe-distance zone — the line is genuinely cut away behind it, not covered with a painted box. Whatever is underneath shows through cleanly. The same goes for the hatched fills: No Fire Area and the contaminated areas cut their hatching away behind the label.

Text also stays upright however you draw the geometry. Draw a bearing line right to left, or steeply downhill, and the letter still reads level rather than upside down.

How exact are these? The point symbols on every Points layer are drawn by the same verified symbol library as the unit symbols, so they are specification-exact. The Lines and Areas are hand-built in QGIS — checked one table at a time against the standard’s own template pictures, not just its text, but still a rendition rather than a spec-exact one. Where something is approximated deliberately, this guide says so. The usual simplifications: a label that the standard repeats on every segment is drawn once instead, because a route traced along a real road has dozens of segments; and the info boxes for controlling headquarters, effective times, widths and altitudes are not modelled anywhere in the appendix.

Where to click

Most lines and areas are simply drawn where you want them: click along the boundary, and the symbol follows your path. But a number of the hand-built symbols are constructed from your clicks rather than drawn along them — your first click might be a centre, your third might set a depth. Get the order wrong and you get a valid-looking symbol facing the wrong way.

Every one of those is below. Draw them with QGIS’s ordinary Add Line Feature tool, clicking the numbered points in order, then right-click to finish.

Contain · 3 clicks
Clicks 1 and 2 are the two ends of the opening, so the line between them is the diameter. Click 3 sets the arrow’s length and which side the opening faces — the arc always bulges away from it.
Retain · 2 clicks
Click 1 is the centre. Click 2 is both the radius and where the arc starts. It sweeps 300° clockwise from there, leaving a 60° opening, ticks pointing outward.
Secure, Occupy, Isolate · 2 clicks
Same construction as Retain, but sweeping 330° for a 30° opening. Occupy replaces the arrowhead with ><; Isolate adds inward-facing triangles off the arc.
Block, Penetrate · 3 clicks
Clicks 1 and 2 set the crossbar. Click 3 sets how deep the stem runs. The letter sits in the crossbar. Penetrate is the same shape with a P, and an arrowhead where the stem meets the bar.
Disrupt, Clear · 3 clicks
Clicks 1 and 2 set the base line, click 3 the depth. Three arrows, letter on the middle one. Click 1 and 2 the way round you want the long arrow to fall — it sits nearest click 1.
Fix · 3 clicks
The arrowhead is at click 1. A straight stretch carries the F, then the shaft waves its way to click 2. Click 3 sets how deep the waves run.
Bypass · 3 clicks
Clicks 1 and 2 are the two arrow tips, not the corners. Click 3 sets how deep the symbol runs. The letter sits on the line joining the two arrows. Either order works.
Breach, Canalize · 3 clicks
Bypass again, with the arrowheads replaced by a slanting bar across each tip. Breach’s pair closes as it runs outward; Canalize’s opens. Which way they lean comes from the geometry, so either click order gives the same symbol.
Delay, Retire, Withdraw · 3 clicks
One shape, four letters — D, R, W, WP. Arrowhead at click 1, shaft to click 2 with the letter set into it, then a semicircle on from click 2.
The arc always leaves click 2 square to the shaft. So click 3 decides how big the arc is and which side of the shaft it falls on — but not which way it points. Only its distance across the shaft counts. Click it on the shaft’s own line and no arc is drawn at all.
Cover, Guard, Screen · 3 clicks
Click one end, then the centre, then the other end. The centre keeps a gap wide enough for a unit symbol, which you place yourself if you want one. Letters either side; a lightning bolt runs out to each end.
Follow and Assume / Support · 2 clicks
Click 1 is the tip, click 2 the rear. Assume’s tag is plain, its line dashed and its head an outlined double chevron; Support’s tag is notched, its line solid and its head a filled triangle.
The tag and the head are a fixed size on the page; only the line between them stretches. Assume’s line stays dashed whether the feature is present or planned — the one place here where a dash does not mean “planned”.
Counterattack · 3 clicks
The arrow runs from click 3 back to an arrowhead at click 1, with CATK along it, dashed throughout. By Fire adds a bracket just past the tip with a small solid arrow through it.
Seize · 3 clicks
Click 1 carries a circle, and the curve starts on that circle’s edge rather than at its centre. It runs through click 2 to an arrowhead at click 3, with S on the curve.
Weapon / Sensor Range Fans · 1 click
One click for the centre; everything else is typed. Up to five rings, each with a left angle, a right angle, a range in metres and an optional altitude.
Angles are compass bearings, clockwise from north; a ring left at 0/360 draws a full circle, and a sector may cross north (300 → 60). Range is real ground distance, so the fan grows and shrinks with the map. Each ring’s straight sides span only its own band, so an outer ring never draws through the inner ones. Blank rings draw nothing; for more than five, place a second fan at the same point.
Minimum Safe Distance Zones · 1 click
One click for the centre, then up to five ranges in metres. Each draws a circle at that true ground distance, with the range written into a break in the ring, level with the centre and to its right. A sixth ring means a second zone at the same point.
Base Defense Zone · 2 clicks
Click 1 is the centre, click 2 sets the radius. It sits on the Lines layer, not Areas, because a centre-plus-radius pair is a two-point line. The standard fixes this zone’s size; the plugin deliberately lets you size it to the ground it covers.
Navigational · 2 clicks
The hazard-marker Z. Click the two corners and the run between them is drawn, then a fixed 6 mm flank at each corner. The two flanks are 180° apart, so the symbol reads the same whichever way round you click.
The flanks stay 6 mm on the page at any zoom — the standard’s own rule that the symbol “varies only in length”. Only the middle run grows.
Fortified Position · 2 clicks
Your two clicks are the two front corners. A leg of fixed depth trails back from each. Only the distance between your points changes the symbol; its depth never does.
The front is always on the left of the direction you digitise. So click left to right along the front with the enemy above the line. The standard only says the front “typically faces enemy forces”, which two points cannot express, so the plugin fixes a consistent convention instead. Fortified Line follows the same rule, with as many points as you like.
Principal Direction of Fire · 3 clicks
Click a far point, then the vertex, then the other far point. You get a two-armed arrow with both heads pointing away from the vertex.
Decoy / Dummy · 3 clicks
Drag out two arms from a shared vertex: one arm end, the vertex, the other arm end. Always dashed — a decoy is a simulated, not-actually-occupied construct, so Status makes no difference.
Battle Position, Strong Point · polygon
An ordinary polygon — but the echelon amplifier is drawn where you started digitising, set into a real gap in the perimeter. Start the polygon where you want the amplifier to appear.
Battle Position also has a Prepared field: set it and the name gets a (P) prefix and the outline draws dashed even if Status is still Present — “prepared but not occupied” is its own dashed variant in the standard. Strong Point adds a spiked border around the whole outline, always pointing outward whichever way you digitised.
Everything else is drawn the obvious way. Boundaries, phase lines, routes, corridors, all the areas — click along the line or around the area and the symbol follows your path. Two habits are worth knowing: Overhead Wire is the one line that puts a pylon at every vertex, so a multi-segment run gets a tower at each bend; and a few point symbols are not centred on your click but sit entirely above it, because their anchor is the tip of a cone at the bottom — Downed Aircrew Pick-Up Point and the five Fires Points.

Control measures: group reference

One entry per group in the Control Measures menu. Use this to find which entry to click for the measure you want.

C2 Measures
LINES · AREAS · POINTS
Lines: Boundary, Light Line. Areas: Area of Operations, Named Area of Interest, Target Area of Interest, Airfield Zone. Points: all 22 command-and-control point types — Checkpoint, Contact / Coordination / Decision Point, Fly-To Point, Rally Point and the rest.
Boundary takes the near unit’s name in Unique designation and the far unit’s in Far designation, stacked above and below the echelon amplifier, and the whole label repeats along a long boundary. The area measures print their fixed abbreviation plus your name — AO BUFFALO. NAI and TAI draw whatever shape you digitise rather than a forced hexagon. Airfield Zone is the exception: no abbreviation, a crossed-runway icon at the centre, and Unique designation means the runway length (750M), printed just outside the boundary.
Maneuver Control Measures
LINES · AREAS

Areas: plain Area, Assembly Area, the Joint / Submarine action areas, Drop / Extraction / Landing / Pickup Zone, Fortified Area, Limited Access Area.
FLOT is one continuous chain of touching arcs. LOC is two chains with a gap between them, bulging toward the opposite side — a )( shape — one always black and one always red, since both sides are shown at once and affiliation does not apply. Offensive Control Measures
LINES · AREAS · POINTS

Areas: Assault Position, Attack Position, Objective Area. Points: Point of Departure.
Direction of Attack is drawn for real — a thin line with a small open chevron head. Axis of Advance is approximated: the standard builds a variable-width tapered ribbon from up to 50 anchor points, and this is a single-width line along your path, so the taper and the small per-type decorations are not reproduced. Probable Line of Deployment is always dashed, in both present and planned status.
Maneuver Control Measures II
LINES · AREAS
Lines: Search Area / Reconnaissance Area, Airhead Line, Bridgehead Line, Holding Line, Release Line. Areas: Encirclement, Penetration Box.
The “II” is only there because the standard gives two different sections the identical title — it is not a lesser or optional set. Airhead Line gets one centred label rather than one at each end.
Airspace Control Measures
LINES · AREAS · POINTS
Lines: the corridor and route family — Air Corridor, Low-Level Transit Route, Minimum-Risk Route, Safe Lane, SAAFR, Transit Corridor, UA Route — plus IFF Off / On Line and Base Defense Zone. Areas: 12 zones — HIDACZ, ROZ, AARROZ, UA-ROZ, the Weapon Engagement Zone family (WEZ, FEZ, JEZ, MEZ, LOMEZ, HIMEZ, SHORADEZ) and Weapons Free Zone. Points: all 26 — ACP, CCP, TACAN, CAP, AEW, Tanking, Orbit and its variants, and the rest.
The routes keep the measure type, colour and name, and drop the taper, the endpoint circles and the width/altitude/time boxes — place separate ACP or CCP points at the ends if you want them shown. Weapons Free Zone gets a genuine hatched fill, because its template requires one. Only three points show a designation: ACP and CCP inside the circle, TACAN outside at top right — typing one on any other entry has no visible effect.
Maritime Control Measures
LINES · POINTS
Lines: Navigational, plus the Bearing Line family — Bearing, Electronic, Electronic Warfare, Acoustic, Acoustic (Ambiguous), Torpedo, Electro-Optical Intercept, Jammer, Radio Detention Finder. Points: the whole vocabulary, 105 symbols.
No Areas layer — this table’s content never reaches an areas heading. 105 points is far too many for one list, so the form asks in two steps: pick a Group first, and the Entity list offers only that group’s symbols — General, Sub-Surface Warfare, Search, Sonobuoys, Reference Points, Subsurface Stations, Surface Stations, Routes, Emergency, Hazard, Sea Subsurface Returns. LINES · AREAS

Draw whichever boundary shape you like — the standard’s separate irregular, rectangular and circular codes render identically once only the boundary differs. No Fire Area has a real hatched fill, and its label masks the hatch. Position Area For Artillery labels all four sides, sitting on the outline with the line breaking around it, as its template draws it. The five Fires Points draw above where you click — their anchor is the tip of the cone at the bottom, not the centre. All three lines get a perpendicular tick at both ends. For Series or Group of Targets, place the individual targets it groups as their own features; only the boundary and name are drawn here.

Obstacle Control Measures
LINES · AREAS · MINEFIELDS · POINTS
The largest group, over four layers. Points: 15 — the mine family, Booby Trap, Engineer Regulating Point, the tetrahedrons and dragon’s teeth, Tower Low and High, Trip Wire, Abatis. Areas: the four serrated zones (Belt, Zone, Free Zone, Restricted Zone), the mined-area family, UXO Area, two freeform dynamic minefields. Minefields: the box-and-glyph family — Completed / Planned, Known Enemy, Suspected or Templated Enemy, Dummy — each with a mine type. Lines: the nine wire obstacles, both antitank ditches, the antitank wall, Obstacle Line, Mine Cluster, the four obstacle effects (Block, Disrupt, Fix, Turn), the three Obstacle Bypass variants, Bridge or Gap, the four Roadblock states, and the water crossing sites.
These draw green, with a per-feature Colour field to switch any one to black; the water crossing sites default to black. Every point here uses Rotation and Scale, and Trip Wire and Abatis draw at a fixed page size oriented by Rotation rather than growing with a digitised line. Bridge / Assault Crossing and Lane / Raft Site are each one entry covering two codes the standard draws identically.
Field Fortification Control Measures
LINES · POINTS
Points: Shelter, Shelter Above Ground, Shelter Below Ground, Fort. Lines: Fortified Line (a crenellated rampart following every bend) and Fortified Position (two front corners, fixed depth). Affiliation-coloured — the obstacle green does not apply here.
CBRN Defense Control Measures
POINTS · CONTAMINATED AREAS · MINIMUM SAFE DISTANCE ZONES · RADIATION DOSE RATE CONTOURS
Points: 18 — the chemical, biological, nuclear and radiological event markers with their toxic-industrial-material variants, a Nuclear Fallout Producing Event, and ten decontamination point types. Contaminated Areas: seven, one per agent plus the TIM variants.
Contaminated areas get a yellow hatched fill — the standard’s colour for contamination, not an affiliation colour — with the matching B / C / N / R triangle centred inside and the hatching cut away behind it. The triangle sizes itself to the area: a steady 12 mm wherever there is room, shrinking only as far as needed to keep 1 mm of clear space at any zoom. A long thin or crescent-shaped area shrinks its glyph sooner than its size suggests, because the fit is measured against the largest circle that fits inside the shape.
For Radiation Dose Rate Contours, draw each contour as its own polygon — three dose rates are three features — and put the bare number in Unique designation (300, not 300cGy; the unit is added for you). This is the one field in the whole appendix not forced to capitals, because the case of “cGy” carries meaning. Note that Nuclear Event and Nuclear Fallout Producing Event draw the same icon — that is the standard’s own doing.
Sustainment Points · Supply Control Measures
POINTS · SUPPLY ROUTES · SUSTAINMENT AREAS
Sustainment Points: 16 — Ambulance Exchange Point, Ammunition Supply Point, Casualty Collection Point, Logistics Release Point, MEDEVAC Pick-Up Point, Traffic Control Post and the rest. Supply Points: 18 — General and Medical Supply Point plus the supply classes. Supply Routes: Main and Alternate Supply Route, each plain or with one-way, two-way or alternating traffic arrows, plus Convoy (moving or halted). Sustainment Areas: seven holding and support areas.
The supply classes are two separate vocabularies — NATO Class I to V plus Multiple Supply Class, and US Class I to X. They share roman numerals and mean different things, so every entry says which standard it belongs to. NATO Multiple Supply Class Point draws the same plain box as General Supply Point, with no icon of its own; the Supply class field is what tells them apart. Pick one to three classes, or ALL — three is the template’s own limit.
Route labels and arrows are drawn once, centred, and stay upright whichever way you draw the line — the standard repeats them on every segment, which is unreadable on a route traced along a real road. Sustainment area lettering is not uniform: the three support areas use an abbreviation (RSA, BSA, DSA) and take no designation, while the holding areas and FARP spell their name out and take one on a line beneath. There is no “DHA” or “RHA”.
Mission Tasks
LINES · POINTS
Points: only three — Destroy, Interdict, Neutralize. Lines: the other 24 — Block, Disrupt, Fix, Penetrate, Clear, Bypass, Breach, Canalize, Secure, Occupy, Isolate, Delay, Retire, Withdraw, Withdraw Under Pressure, Relief in Place, Cover, Guard, Screen, Follow and Assume, Follow and Support, Counterattack, Counterattack by Fire, Seize.
Nearly all of these are constructed from your clicks rather than drawn along them — Where to click covers every one. Each carries its own letter, set into a real gap cut in the shaft or arc.
These are not the obstacle effects. Block, Disrupt and Fix each appear twice in the standard, under different codes and different drawn forms. The Obstacles layer’s versions draw green; these draw black. Relief in Place is the Delay shape with no letter, so its line runs unbroken, plus a second arrow pointing back the other way, with RIP in the middle — and that text grows with the symbol up to 24pt. Security itself draws nothing, because the standard gives it no template, so there is no entry for it.
Deception · Intelligence Control Measures
LINES
One symbol each. Decoy / Dummy — a dashed tent shape, always dashed. Intelligence Coordination Line — ICL plus your designation at both ends, the same construction as the Battlefield Coordination Line.
No AEGIS-only symbols anywhere. The standard marks a handful of entries “AEGIS only” — naval combat-system display constructs rather than general-purpose symbology. None of them are offered. If you placed one before they were withdrawn, the feature keeps its attribute value but no longer appears in the dropdown. Two other deliberate omissions: Position and Intended Movement Route, because the underlying library maps it to the wrong picture and a wrong symbol is worse than none; and Decoy/Dummy and Feint, which modifies another separately-drawn measure rather than standing alone.

Expression functions

These let you use the plugin’s calculations inside QGIS’s own expressions — in a label, a field calculator, a layout item. You do not need them for ordinary work; they are there when you want to build something the dialogues do not cover. Find them under the Military Cartography Tools group in the expression editor (the fx button on any field). Arguments in square brackets can be left out.

mct_mgrs_zone(lat, lon)
Grid Zone Designator, e.g. 37M

Symbology and measurement

mct_build_sidc(affiliation, entity, symbol_set, echelon, status, headquarters, [sector1], [sector2])
A 20-character SIDC built from named parts
mct_sidc_svg(sidc)
The rendered symbol, as a path you can use directly as an SVG marker
mct_area_km2($geometry)
A polygon’s true area in km²
mct_perimeter_km($geometry)
A polygon’s true perimeter in km
mct_length_km($geometry)
A line’s true length in km

The last three measure against the project’s coordinate system, since a bare geometry carries none of its own. That is correct for any layer this plugin creates, because they are always built in the project’s CRS. If you reuse them on a layer whose CRS was later changed independently, reproject the layer to match first.

Every function returns a short error string — Layout not found, Need latitude, longitude — rather than failing silently, so a wrong argument shows up in the label instead of leaving you guessing.

When things look wrong

My non-NATO symbol is the wrong colour, or will not change colour
On the mine family and on Minefield (General), Affiliation is ignored on purpose — those are always green. Everywhere else, colour comes from Affiliation alone and the frame shape never changes, so a hostile non-NATO unit is a red rectangle, not a diamond. See Section 12.
I set Status to Dashed and nothing happened
On the Land Unit family it dashes the frame. On Control Measure Points it only changes six of the twenty-seven — Air Head, Beach Head, Bridge Head, Command Post, Vital Area and Vital Point. The others are built from a symbol drawn solid either way. Nothing is broken; there is simply no frame to dash.
My minefield line is just two empty parallel lines
Mine type has not been set. With no mine type chosen there is nothing to draw between the rails. Pick Antipersonnel, Antitank or Both in the attribute form.
I chose an echelon and the symbol did not change
Not every entity draws one. The four Enemy entities, the six plain Aviation entities and all ten Ammunition and FOL entities have no echelon in their drawing, although the field is still on the layer. The table in Section 12 lists which entities use which marks.
I cannot draw anything — the tools are greyed out
Select the layer in the Layers panel, then switch editing on with the yellow pencil. QGIS’s drawing tools only work on the one selected editable layer.
My sensor coverage has not appeared
Save the layer edits. Coverage is only drawn on save, because each sensor is a full viewshed calculation. After reopening a project, use Regenerate Sensor Coverage.
My sensors vanished when I reopened the project
Sensor Points layers are temporary until you make them permanent. Right-click each one → Make Permanent, save to a GeoPackage, then save the project. Do not rename the layer afterwards — coverage is matched by name.
A coverage or viewshed edge is suspiciously straight
You have run out of terrain. Analysis stops at the edge of your DEM. Check the sensor’s range against the DEM’s extent before reading anything into that shape.
A terrain tool refuses to run
There is no elevation raster in the project, or the one you picked does not cover the ground you clicked. See Getting a DEM.
Tanaka Contours seems to have frozen QGIS
It is probably still working — there is no progress bar. A big DEM with a fine contour interval and a short segment length is a great deal of computation. Crop the DEM to your area, or start with a coarser interval.
My grid does not line up with the area I have moved to
Grids are built once for the extent you were viewing. Run Clear Grid, then switch them back on where you are now.
Illuminated overlay contours are almost invisible
That style is meant to blend with what is beneath it. Put a Hypsometric Tint underneath, or choose Elevation colour or Monochrome instead.
A menu entry warned me instead of adding a layer
That layer already exists and holds your hand-placed data, so it will not be replaced. Rename the existing one if you genuinely want a second.
My designation is not showing on a point symbol
Some icons have nowhere to put one. Among the airspace points only ACP, CCP and TACAN show a designation; typing one elsewhere has no effect. The US supply classes are similar — their icons have no internal text position, so theirs draws outside the box.
My symbol is the right shape but facing the wrong way
For points, set Rotation. For a constructed line, you clicked the points in the wrong order — check Where to click. Remember the two fixed conventions: fortifications put the front on the left of the digitising direction, and the Delay family’s arc leaves click 2 square to the shaft whatever angle you clicked click 3 at.
A maritime point refuses to save
The Entity has to belong to the Group you chose. If you changed the Group after picking an Entity, pick again from the new list.
A CBRN triangle is much smaller than I expected
Long thin or crescent-shaped areas shrink their glyph sooner than their size suggests, because the fit is measured against the largest circle that fits inside the shape. That is what keeps the clear space around it honest at any zoom.
Map Sheet Series refused to run
Your page size and scale would make more than 200 sheets. Zoom in to a smaller extent, or choose a smaller-scale map.
My series sheets are nowhere to be found
They are registered but not opened, since a large series would mean dozens of windows. Open them from Project → Layouts Manager.
Grid numbers are written across my printed map
Use Add Grid Frame in the layout window. It puts the numbers on the neatline and hides the on-map labels for that layout only.
The toolbar has disappeared
Right-click any empty part of the QGIS toolbar area and tick Military Cartography Tools. Everything is also under Plugins → Military Cartography Tools.

Words and shortenings

CRS
Coordinate reference system — the projection and datum a layer’s coordinates are measured in.
DEM
Digital elevation model. An elevation raster: a picture of the ground where each pixel holds a height.
Combined Arms
A mark on a non-NATO Land Unit showing a grouping of more than one arm.
Designation
Your own text beside a symbol — a unit’s number and name, or a point’s label. It sits outside the symbol and never shrinks it.
Echelon
The size of a formation, drawn as ticks or bars above the symbol.
FOL
Fuel, oil and lubricants.
Mobility
A mark under a piece of equipment saying how it moves — self-propelled or tracked.
Non-NATO
The separate symbology scheme in Section 12. Not part of MIL‑STD‑2525 or APP‑6, and kept on its own layers.
DTG
Date-time group, e.g. 051030Z.
Digitise
To draw a feature by clicking its points on the map.
Extent
The rectangle of ground a map window or a layer covers.
GZD
Grid Zone Designator — the big lettered and numbered UTM zone box, e.g. 37M.
Graticule
Lines of latitude and longitude, as opposed to a projected grid.
Hypsometric
Coloured by height.
Layout
QGIS’s word for a page you are preparing to print.
MGRS
Military Grid Reference System — the grid reference military maps are read in.
Neatline
The border ruled around the edge of a printed map.
Raster / Vector
A raster is made of pixels (a photo, a DEM). A vector is made of points, lines and areas.
SIDC
Symbol identification code — the 20-character code that identifies one military symbol exactly.
Tanaka
A contour style where line thickness varies with how the slope faces the light, so the lines themselves show relief.
UTM
Universal Transverse Mercator — the projection MGRS is built on.
Viewshed
The ground visible from a given point. What is left blank is dead ground.
WMM
World Magnetic Model — what the plugin uses to work out magnetic declination for a date.
